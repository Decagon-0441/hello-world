## Program: Spacer
# This program asks the user for a string input (their name), and a reasonable integer (any integer works). 
# Then, the program takes the users input name and will add the integer number of spaces between each character in the name. If the character itself is a space, then it will not add any additional spaces and proceed to the next character in the provided string. 
# This program is simply just for fun and a way to mess around with the inputted name.
